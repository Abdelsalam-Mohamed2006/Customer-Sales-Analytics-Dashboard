#  Customer & Sales Analytics Dashboard

##  Project Overview
An interactive dashboard built using Excel and Power BI to analyze customer behavior, sales performance, and purchasing patterns.

##  Project Objectives
- Analyze customer demographics.
- Understand purchasing behavior.
- Evaluate product performance.
- Identify sales trends.
- Generate actionable business insights.

##  Project Workflow

### 1. Data Understanding
Explored the dataset to understand its structure, columns, and data types.

### 2. Data Cleaning
Handled missing values, duplicates, inconsistencies, and formatting issues.

### 3. Data Analysis (Excel)
Used Pivot Tables to summarize data, calculate metrics, and identify trends.

### 4. Dashboard Development (Power BI)
Created an interactive dashboard using KPIs, charts, slicers, and DAX.

##  Key Insights
- Clothing was the best-selling category.
- Medium (M) was the most purchased size.
- Footwear achieved the highest average customer rating.
- Most customers were not subscribed.
- Free Shipping was the most preferred shipping option.

##  Business Recommendations
- Improve clothing quality.
- Develop customer loyalty programs.
- Optimize inventory based on popular sizes.
- Improve customer retention.
